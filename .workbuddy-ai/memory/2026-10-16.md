### 关键踩坑（重要，后续改动勿踩）
1. **Excalidraw onChange 无限回灌**：`handleChange` 里无条件 `setElements/setSelectedIds` → 新数组引用 → React 抛 `Maximum update depth exceeded` 白屏。必须用 `sceneSignature()`（id:version:opacity:locked）做内容级比较后再落 state。
2. **程序化 `updateScene({appState:{selectedElementIds}})` 不触发 onChange**：图层选中必须由面板回调直接同步平台侧选中态。
3. **改元素属性必须 bump `version`/`versionNonce`/`updated`**，否则 Excalidraw 判定"无变化"丢弃更新（显隐/锁定失效）。
4. Excalidraw 原生"双击裁剪"需用 `onDoubleClickCapture` 拦截 + CSS 隐藏 `.HintViewer`，否则与单击编辑冲突。
