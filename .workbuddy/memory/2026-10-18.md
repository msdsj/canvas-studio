  ```
  > 260 | export const ImageEditLayer = forwardRef<ImageEditLayerHandle, ImageEditLayerProps>(
  ```
  Babel 解析器**连续报7 次**同一错误后进程退出。
- 事后 `tsc --noEmit` 0 error → 仍是**编辑中途保存的半成品状态**，代码本身没坏。
- **模式总结**：Vite 在文件语法不完整时被反复触发 HMR 解析，连续失败若干次后 dev server 会挂掉。遇到「点了没反应/页面不更新」先看 vite 日志有没有 `Internal server error`。
- **给用户的建议**：大段重构时避免在语法不完整状态下连续保存；先跑 `npm run typecheck` 再刷新页面。
- **复现确认（9:19）**：在文件仍处于半成品状态时启动前端，Vite `Pre-transform error` 连续 5 次后进程立刻退出（22秒）。等文件修好（`tsc` 通过）再启动即稳定。**结论：这不是服务稳定性问题，是「保存了语法不完整的文件」导致的必然结果** —— 排查顺序应为：先 `tsc`，再重启。
