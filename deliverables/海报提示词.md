# Canvas Studio 朋友圈海报 · 生图提示词

> 三个方向 + 一个文字兜底版。直接复制代码块里的内容丢给模型。
> 视觉基准：`docs/09-visual-language-v2.md`「工作室纸感」——纸白 `#F8F5F0` / 陶土橙 `#B5502C` / 靛蓝 `#3D5A80`（仅选区）/ 暖墨 `#201C17`。

## A · 桌面静物版（推荐｜最有质感，最不像 AI 图）

构图叙事：桌面上摊着相纸，有人刚在纸上圈了一块。**不用任何 3D、渐变、光效**，全靠材质和光。

```
竖版 3:4 摄影海报，俯拍视角，温暖的米白色纸面桌面，柔和自然光从左上斜射，物体投下浅淡的暖棕色长影。

画面主体：桌面上散落三张略微倾斜的白色相纸，边缘是 3 毫米直角，纸面哑光细腻。中间那张最完整，上面是一张猫咪的彩色照片；这张照片上叠着一个细的靛蓝色矩形选框，线宽约 2px，四角带小小的方形手柄。框内的猫清晰锐利、色彩饱满，框外的画面被轻微褪色、发灰、柔化——只有框内是"活的"。

相纸左上角压着一张米色便签纸，上面有手写的黑色中文小字："背景换白的"。一支削过的木杆铅笔斜放在相纸右侧，笔尖朝左下。

画面上方留出大片空白，排一行巨大中文标题，深暖墨色 #201C17，衬线宋体，笔画厚重："改这块，别动别的"。标题下方一行小号无衬线字："框一块地方，说一句想怎么改"。

右下角小字署名："Canvas Studio"。

色彩：整体暖白纸调 #F8F5F0；陶土橙 #B5502C 作为唯一强调色，用量不超过画面 10%；靛蓝 #3D5A80 只出现在选框线条上；文字用深墨 #201C17。所有阴影是暖棕 rgba(32,26,18,0.12)，绝不使用纯黑阴影。

质感：真实摄影，50mm 定焦，浅景深，细腻胶片颗粒，纸纤维可见。像一本设计杂志的封面——安静、克制、有手工温度。

不要：3D 渲染感、玻璃拟态、霓虹光、蓝紫渐变、发光粒子、等距科技插画、塑料高光、夸张科技感、乱码文字、变形的手指、屏幕与界面元素。
```

## B · 极简符号版（朋友圈缩略图最抓眼）

整个画面只有两个东西：**一个框，一句话**。朋友圈信息流里缩到 200px 宽也能一眼看懂。

```
竖版 3:4 极简艺术海报。整幅是温暖的纸白色 #F8F5F0 背景，带极细的纸纤维纹理和轻微的边缘暗角。

画面正中偏下：一个巨大的、手绘感的不规则四边形选框，线条是深陶土橙 #B5502C，笔触有轻微抖动与粗细变化，像用马克笔在纸上画出来的。选框内部是整幅画里唯一"有内容"的区域——一小块猫咪照片，色彩饱和清晰；框外完全空白，只有纸。

框的右上角引出一条极细的靛蓝色 #3D5A80 指示线，连到一小块米色便签，便签上是手写中文："背景换白的，猫别动"。

画面上方三分之一，巨大的中文标题，深墨 #201C17，衬线宋体，分两行排：
"改这块"
"别动别的"
标题字号极大，横向占据画面宽度的 80%。

底部一行细小的无衬线字："Canvas Studio · 无限画布 + 对话改图"。

气质：一张艺术展海报。大量留白，极度克制，除了一个框和一句话什么都没有。

不要：任何 3D 元素、渐变、发光、装饰图形、图标、杂乱背景、多余的色彩。
```

## C · 纸片演变版（想说"一次出多版"就用这个）

用三张相纸并排讲"同一只猫的三个版本"，比任何文案都直观。

```
竖版 3:4，暖白纸面背景，俯拍视角。

画面中下部横向并排摆着三张白色相纸，略微错落，角度各异（-4度、0度、3度），每张都投下淡淡的暖棕色阴影，像纸叠在纸上，纸张的厚度和毛边清晰可见。

三张相纸上是同一只猫的三个版本：左图背景是杂乱的房间，中图背景换成干净的暖白色，右图是抠出的猫、纯白背景。中间那张覆盖着一个靛蓝色 #3D5A80 的矩形选框，四角有方形手柄，框顶有一个小小的陶土橙 #B5502C 圆点，里面是数字"1"。

画面上方留白处一行中文大标题，深墨 #201C17，衬线宋体："一次说三件事，一次出三张"。

底部小字："Canvas Studio"。

风格：真实摄影的纸片静物，柔和自然光，浅景深，安静的工作室桌面。

不要：电脑屏幕、软件界面截图、UI 控件、3D 渲染、发光、渐变、科技感、多余文字。
```

## D · 兜底版（不要文字，后期自己贴）

**中文渲染失败率不低。** 如果 A/B/C 出来的字是糊的、错字、或外星文，用这一版，然后去即时设计 / Figma / 稿定里自己贴字——几十秒的事，比反复抽卡划算。

```
竖版 3:4 摄影海报，俯拍桌面静物，温暖的纸白背景 #F8F5F0。

一张白色相纸居中，略微倾斜，纸上是猫咪照片；照片上叠着一个细的靛蓝色 #3D5A80 矩形选框，线宽 2px，框四角有小方形手柄。框内清晰锐利、色彩饱满，框外轻微褪色虚化。

相纸左上角压一张米色便签，右侧斜放一支削过的木杆铅笔。

画面上方留出约 35% 的纯净空白（后期加字用），不要有任何元素。

柔和自然光，浅景深，细腻胶片颗粒，暖棕阴影 rgba(32,26,18,0.10)，安静克制的工作室桌面氛围。

不要：任何文字、字母、数字、水印、logo、签名、3D 渲染、发光、渐变背景、霓虹、蓝紫色调。
```

# 使用要点

## 1. 尺寸

**3:4 竖版，1080×1440。** 朋友圈单图、九宫格首图都是竖图占屏最大。别做 16:9——在手机上会缩成一条，什么都看不清。

## 2. 字必须大

朋友圈信息流里的缩略图大约只有 **200px 宽**。这意味着海报上的主标题至少占画幅高度的 **1/6**，否则等于没写。A 版那句"改这块，别动别的"就是这个逻辑——六个字，四个字是重点。

## 3. 配色不要交给模型自由发挥

`#F8F5F0`、`#B5502C`、`#3D5A80`、`#201C17` 这四个值要写死在提示词里。AI 生图默认会给你蓝紫渐变 + 玻璃质感 + 发光粒子，那是"AI 味"最重的三件套，和你产品的纸感调性完全相反。

## 4. 一次生成 4 张，只挑一张

别指望第一张就成。同一个提示词跑 4 张，挑构图最好的那张；字糊了就换 D 版 + 后期加字。

## 5. 模型适配

| 模型 | 建议 |
|---|---|
| gpt-image-2 / GPT-Image | 中文短句成功率高，直接用 A 版；size 选 1024×1536 |
| Nano Banana / Gemini Image | 中文好，A 版几乎能一次成，可加"keep text large and legible" |
| 即梦 / Seedream 4.0 | 中文强，但要强调"竖版 3:4"，否则默认出方图 |
| Midjourney | 基本不出中文，**直接用 D 版**，后期加字 |

## 6. 配套正文

海报只是图，朋友圈还得有那几句话。正文用 `deliverables/朋友圈文案.md` 里的 A 版（降维吐槽）最搭——图上是"改这块，别动别的"，正文里是"生图是抽卡，改图才是干活"，一句视觉一句观点，不重复。
