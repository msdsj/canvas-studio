# Canvas Studio 朋友圈文案

> 4 个版本，按人设挑一个发。每版都可直接复制。

---

## A · 降维吐槽版（最贴合"还在用生图的吗"的调性｜推荐）

还在用"生成十张挑一张"的方式做图吗？
还在为改一个字，让 AI 把整张重画一遍？

我现在是这么干的：
图丢进画布，圈住背景，写"换成白色"。
圈住猫，写"抠出来"。
圈住那行标题，写"改蓝、加粗"。
点生成，一次给我三张。

最爽的是——它只动我圈的地方，其他地方一根毛都不变。

生图是抽卡。
改图才是干活。

Canvas Studio：无限画布 + 对话改图，我们自己做的。
想试的私我。

---

## B · 真实体验版（程序员 / 产品人发，不像广告）

说个实话，我最近做图已经不开 PS 了。

以前的流程：生图软件抽卡 → 挑一张勉强能看的 → 进 PS 抠图、换背景、改字 → 不满意，回第一步重来。
现在的流程：图扔在画布上，圈住想改的地方，用人话说一句。
"背景换白的"、"猫抠出来"、"这句改成蓝色"
三件事一起说，一次出三张结果。

而且结果直接落回画布，可以并排摆着对比，不满意接着说下一句，上下文它记得。

这几年 AI 生图最大的问题是：它只会从零画，不会改。
现在这个会改了。

（Canvas Studio，我们做的，想试私我）

## C · 甲方 / 接单版（做运营、接设计单的人最有共鸣）

客户："背景换成米色，字大一号，猫别动。"

改完直接并排摆在画布上，让客户自己选。
沟通成本直接砍一半。

（Canvas Studio，我们自己做的，想试私我）

# 配图与发布建议

## 配图（这一步比文案更重要）

| 顺序 | 用哪张 | 为什么 |
|---|---|---|
| 首图 | 工作台全景：画布上多张图并排 + 左侧对话流 | 一眼看出"这是个正经工作台"，不是又一个网页小工具 |
| 第二张 | 红框 / 涂鸦标注的特写 | 最有说服力的一张，"圈一下就能改"的视觉证据 |
| 第三张 | 改前 vs 改后 对比 | 结果感，直接闭环 |
| 备选 | 对话里"思考过程 4 步"的截图 | 显得这产品是真在理解需求，不是在瞎画 |

**别放**登录页、落地页、定价页——那三张一出现，整条就从"分享"变成"广告"，划走率翻倍。

## 发布细节

1. **第一行决定有没有人点"全文"**，折叠线大约在第二行末。钩子必须压在折叠线以上。
2. **时间**：晚 21:30–23:00 或 午 12:00–13:00，朋友圈刷得最勤的两个窗口。
3. **评论区自补一句**，比正文有效得多。例如：
   > 图1那张，从上传到出图 40 秒，中间我没碰过一次 PS。
4. **如果还没开放注册**，把"想试的私我"换成"想试的我开几个号，先到先得"——稀缺感比推销感管用。
5. 如果嫌 A 版太冲，把"一根毛都不变"改成"一个像素都不动"，攻击性低一些，专业感强一些。
