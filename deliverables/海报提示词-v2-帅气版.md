# 朋友圈海报 · 生图提示词 v2「AI / Agent 感」

> 上一版走的是"设计杂志静物"——安静、有质感，但不够帅，看不出这是个 AI 产品。
> 这一版换了个思路：**不画 AI，画 AI 干活的样子。**
>
> 关键判断：发光神经网络、蓝紫粒子、全息投影、机械臂——那是 2019 年的 AI 视觉，今天看反而最廉价。
> 真正高级的 AI 感只有三个来源：**精确的标注线、正在发生的改写、被拆开的结构。**
> 全部落在你的品牌色里（纸白 / 暖墨 / 靛蓝 / 一点陶土橙），高级且不撞款。

---

## ① 「正在改写」｜最抓眼，缩略图最清楚（推荐首发）

一张照片被一条扫描线切开：左边已经被改完，右边还是原样。**"改"这个动作，被拍下来了。**

```
竖版 3:4 高端产品海报，俯拍桌面，极简构图。

画面中央是一张大幅白色相纸，斜放在温暖的米白色纸面上（约 4 度倾斜）。相纸上是一张猫咪照片，被一条垂直的扫描线从正中分开——

扫描线左侧：背景已经被换成纯净的暖白色，猫的边缘干净利落，毛发锐利。
扫描线右侧：还是原本杂乱的房间背景，整体偏灰、偏暗、轻微去饱和。
两侧的色调差异极其明显，分界线笔直、锐利，像画面正在被实时改写。

扫描线本身是一条约 3px 宽的纯白细线，两端略微过曝。它不发光、不散射、没有光晕——就是一条干净的光带，像扫描仪的灯管。

相纸上叠加了一层极简的机器视觉标注：一个细靛蓝色 #3D5A80 的矩形选框（线宽 2px，四角有小方形手柄）精确贴住猫的轮廓，框的右上角引出一条极细的直线，连到相纸外侧的一个小圆角标签。标签是米白色，内有等宽小字："01 · 重绘背景"。整张纸上只有这一个标注，不要更多。

画面上方留出大片纯净留白。排两行巨大中文标题，暖墨色 #201C17，衬线宋体，笔画厚重、字距收紧：
"它 正 在 改"
下面一行小字，无衬线："框住的那块，才是它的工作区"。

右下角极小的一行："Canvas Studio"

色彩：纸白 #F8F5F0、暖墨 #201C17、靛蓝 #3D5A80、一点陶土橙 #B5502C（只用在标签上的一个小圆点，面积不超过 3%）。
阴影：暖棕 rgba(32,26,18,0.10)，短、实、贴近物体，绝不发灰。

质感：真实摄影，85mm 微距，浅景深，看得见纸纤维与细微墨点。整体像实验室里的精密仪器——干净、准、安静。
气质：不是科幻，是工程感的高级。

不要：蓝紫渐变、霓虹、发光、光晕、粒子、电路板、神经网络、全息投影、3D 玻璃、机器人、塑料高光、赛博朋克、夸张特效、多余的文字。
```

## ② 「一句话，三个任务」｜最 Agent，信息量最大

三个不同颜色的框，三条引线，三个小标签——这就是 agent 把一个指令拆成三份工作在同时处理的样子。

```
竖版 3:4 俯拍概念海报。

温暖的米白色纸面上，一张大白相纸居中，上面是一张完整的室内照片：一只猫坐在地毯上，左边有窗，右下是地毯边缘。

这张照片上叠加了三个互不重叠的细线选框，颜色克制而分明：
· 窗的位置——靛蓝色 #3D5A80
· 猫的身体——陶土橙 #B5502C
· 地毯右下角——深石板灰 #4A4A48
每条选框线宽 2px，四角带小小的方形手柄，转角锐利。

每个框的右上角引出一条极细的直线，连到相纸外侧的三个小圆角标签，标签在画面右侧呈扇形散开、互不遮挡。标签内是等宽小字，只写三行：
"01 换背景"
"02 抠主体"
"03 改地毯"

框内的画面比框外明显更清晰、更饱和、更亮；框外整体轻微发灰、去饱和——就像三个工作区正在被同时点亮。

画面上方留白，巨大中文标题，暖墨 #201C17，衬线宋体，分两行：
"一句话"
"三个任务"
下方一行小字："它自己拆，自己派，自己交"。

右下角小字："Canvas Studio"

全图不出现任何发光效果。所有"智能感"来自线条的精确与秩序的克制。

不要：彩虹色标注、霓虹、渐变、全息、3D、机器人、网络连线、粒子、杂乱背景、多余装饰。
```

## ③ 「它看见的不是一张图」｜最"AI 理解"，最像大厂发布会

一张照片被水平炸开成四层薄卡纸——背景、主体、文字、光，是四件可以被分开的事。

```
竖版 3:4 概念海报，俯拍，大量留白。

画面中央偏下：一张猫咪照片悬浮在温暖的纸白背景 #F8F5F0 之上，被水平"炸开"成四层薄片，每一层向下错开约 14px，层与层之间只有极淡的暖棕色阴影。材质是四张薄卡纸，边缘有细微的纸厚度，不是玻璃也不是屏幕。

从上到下：
第一层：完整的猫咪照片，最亮、最清晰。
第二层：只有猫的轮廓和毛发，背景被完全剥离，四周透明。
第三层：只有房间背景，猫的位置是一块干净的留空。
第四层：只有画面里那片窗光的高光形状，纯白，像一张光的地图。

每层边缘是极细的靛蓝色 #3D5A80 描边（1px）。层与层之间用一条垂直的细虚线连接，暗示它们属于同一张图。

画面上方三分之一的留白里，两行巨大中文标题，暖墨 #201C17，衬线宋体：
"它看见的"
"不是一张图"
下方一行小字，无衬线："是背景、主体、文字、光——四件可以分开改的事"。

右下角小字："Canvas Studio"。

光线：顶部柔和漫射光，投影极短、极淡，没有方向性。
质感：干净的纸，真实的厚度，安静的秩序。

不要：3D 渲染、玻璃材质、发光、渐变、科技蓝、悬浮的粒子、科幻界面、多余的文字。
```

## ④ 「指尖改写」｜最有魔法感（手部有翻车风险，多抽几次）

手指碰到的地方，画面就变了。**这是整个产品最像魔法的一瞬间。**

```
竖版 3:4 微距俯拍海报。

画面：一只手的食指正轻轻按在一张白色相纸的照片上，只有手和一小段手腕入镜，从画面右上角伸入，皮肤纹理真实，指甲干净，没有首饰。

指尖接触的那一小块区域，画面已经被改写：原本照片里是灰色的墙面，指尖所触之处变成了干净的暖白色，边缘围绕指尖呈一个柔和的圆形过渡。改写区域不超过指甲盖大小。

照片上叠加一个极细的靛蓝色 #3D5A80 矩形选框，正好包住这块被改写的区域，线宽 2px，四角有小方手柄。

背景是温暖的米白色纸面，完全干净。画面上方和左侧留出大片留白。

左侧留白处竖排两行巨大中文标题，暖墨 #201C17，衬线宋体：
"碰 一 下"
"就 改 这 块"
下方一行小字："不用重画，不用重来"。

右下角小字："Canvas Studio"。

光线：柔和侧光，手背有细微的高光和绒毛，投影短而暖。
质感：真实摄影，100mm 微距，浅景深，皮肤和纸的纹理都清晰可信。

不要：变形的手指、多余的手指、六个指头、塑料感皮肤、发光、魔法光效、粒子、渐变、科幻感、美颜磨皮。
```

# 让它更帅的四条操作经验

## 1. 别让模型自己配色

四个 HEX 写死在提示词里：`#F8F5F0` `#201C17` `#3D5A80` `#B5502C`。只要漏了，模型 90% 会给你蓝紫渐变——那是它训练数据里"AI"的平均长相，也是这条朋友圈最容易被划走的原因。

## 2. "不发光"要反复强调

扫描线、选框、标注，任何一处发光都会瞬间掉档。提示词里要用"纯白细线 / 不发光 / 不散射 / 没有光晕"这类否定词压住它。

## 3. 小标签文字大概率会崩

① ② ④ 里的"01 重绘背景"这类小字，生图模型经常出乱码。两个处理方式：
- 生成时把标签留空（提示词里删掉文字内容，只写"空白标签"），后期自己贴
- 或者干脆不要标签，只保留框和引线——**更干净，也更高级**

## 4. 最帅的做法其实是：图上不要字

真正像设计师作品的，是**纯视觉 + 后期排版**。如果你用 ③ 或 ①，可以让我再出一版"无文字版"提示词，你拿到画面后去即时设计里排标题——字可以排得比模型好十倍，而且能随时改。
