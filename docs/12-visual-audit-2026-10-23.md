# 全站视觉与动效审计（2026-10-23）

> 审计方式：Playwright 无头 Chromium，1440×900 与 390×844，亮/暗双主题，
> 覆盖 21 个路由。截图存 `/tmp/audit-shots/`（亮/暗各一套）与 `/tmp/audit-full/`（整页）。
> 基础结论：**0 控制台错误、0 横向溢出**——功能链路是通的，问题集中在「一致性 / 留白 / 信息密度 / 局部缺陷」。

## 一、全局性缺陷（影响所有页面）

### A1. 背景环境光溢出到所有页面
`body` 上写死了 `--ambient-1/--ambient-2`（青柠 + 暖砂两团径向光），但它本是为首页设计的。
在所有内容页上，这层光在左上角形成**黄绿色雾**，与米白纸底打架，看起来像"没擦干净的背景"。
- 证据：`frontend/src/index.css` `body { background-image: var(--ambient-1), var(--ambient-2); background-attachment: fixed; }`
- 影响页：`/assets` `/projects` `/settings` `/usage` `/admin/*` 全部
- 期望：环境光只在首页与登录页生效（页面级背景），内容页用纯净纸底 + 纸张噪点。

### A2. 页面容器不统一（最刺眼的"不像一套产品"）
| 页面 | 标题左内边距（1440 视口） | 容器 |
|---|---|---|
| `/assets` `/projects` `/tasks` `/usage` | 104px | `PageShell` 默认 1240 |
| `/settings` | 238px | 自建窄容器 |
| `/skills` | 188px | 自建容器 |
| `/team` | 56px | 自建全宽 header 带 |
| `/admin/*` | 203px | `AdminShell` 自己的壳 |

每个页面各写一套 header，标题字号 / 描述位置 / 操作按钮位置/ 分隔线都不一样。
- 期望：普通页统一 `PageShell`；管理后台 `AdminShell` 复用同一套 header 规格；团队页也走同一套。
- 同时给 PageShell 补：`tabs` 插槽、`sticky` 页头、统一的 24/32/40 三档 gutter。

### A3. 空状态千篇一律且过于空洞
现状：一个 48px 灰圆 + 一行标题 +（有时）一行说明，垂直位置各页不同（180px / 235px / 居中）。
`/tasks`「No active tasks」、`/team`「No teams yet」、`/projects` 只有一个项目时整页 80% 空白。
- 期望：统一 `EmptyState` 组件，含：图形（描边 SVG，非 emoji）、标题、说明、主行动按钮、可选的"提示列表"。
- 卡片网格页追加一张"新建"幽灵卡，避免大留白。

### A4. 数据表格无外框、无吸底分页
`/admin/users` `/usage` `/admin/logs`：表头米色横条直接铺在纸底上，表格没有卡片外框，
行数超过一屏时**分页被挤到视口外**，看不到总数。
- 期望：表格包在 `Card` 内（圆角 + 边框 + 内阴影），分页条 sticky 在卡片底部，行 hover 有明显反馈。

### A5. 动效不统一
- 各页面入场节奏不同（有的 GSAP，有的 CSS，有的没有）。
- 存在动画 `box-shadow` / `filter` 的实现（会掉帧）。
- 没有 `prefers-reduced-motion` 的全局兜底。
- 期望：统一 motion token（`--dur-1..4` + 三条 ease），只用 `transform/opacity` 做动画，
  统一 `useReveal` 入场（y:12 / stagger:0.06），全局 reduced-motion 降级。

## 二、单页缺陷

### W1. `/workspace` 工作台（最需要修）
1. **底部工具条文字换行**：「Add image to canvas」「Upload image」被挤成两行，按钮高度撑高，整条工具条歪斜。
2. **缩放控件重复**：左下和右下各有一组「− 29% +」，功能重复，视觉噪声。
3. **左侧悬浮缩略图列**：画布左边缘 x≈290 处有一列 3 张约 28px 的小缩略图，遮挡画布内容，
   疑似 `CanvasNavigator` 定位错误（应贴边收起或放进图层面板）。
4. **Toast 遮挡对话**：「This one didn't come through…」浮在对话面板中部，压住消息气泡，
   且标题被截断成「GFT im…」；重试按钮与文案挤在一起。
5. **工具选中态用了紫色**：画布顶部工具条第二个图标激活底色是淡紫（off-palette），
   与青柠/墨黑体系冲突。
6. **对话面板过窄**：约 230px，导致「Add to canvas / Generate again」两个按钮换行，
   消息卡片内文字被压成 3–4 字一行。
7. 画布顶栏右侧「版本 1」被截成「e 1」，badge 宽度不足。
8. 工具条图标大小不一（16/18/20 混用），基线不齐。

### P1. `/projects`
1. 项目卡封面是灰色空态网格图标——项目里已有画布图片却不出封面（功能缺口）。
2. 卡片仅 210px 宽，1440 下显得孤零零；网格未做自适应列数。
3. 分页条孤悬在内容下方 100px 处。
4. 整页只有一个项目时，80% 是空的，没有引导。

### T1. `/tasks`
1. 空状态无说明、无行动按钮。
2. 页面只有标题，没有任何筛选/分组（状态 / 时间 / 类型）。

### S1. `/skills`
1. **底部内容被裁切**：最后一行卡片「艺术摄影」只露出半个标题，页面无底部安全间距。
2. **浮动「Save selection」条压住卡片**：遮住最后一行卡片的开关。
3. 开关（Enabled/Off）退化成 11px 小字，几乎没有可点击暗示；卡片 footer 左「13 skills」右「Off」两端对齐，中间大片空。
4. 卡片描述 12px 灰字，字号偏小、行高偏紧，中文阅读吃力。

### U1. `/usage`
1. **「Total granted 0」与余额 11534 矛盾**（语义错误或接口未返回），用户会以为额度来路不明。
2. **价格行溢出**：4 个价格块贴到卡片右边、等于没有内边距。
3. 余额列（Balance）连续多行相同值（11534/11534/11534），像是"当前余额"而不是"该笔后余额"。
4. 没有消耗趋势图——用量页却没有曲线，是最大的信息缺失。
5. 时间格式 `10/21/2026, 10:22:06 PM` 为 en-US，与中文界面不一致（未走 `useFormatters`）。
6. 表格无外框卡片，无类型筛选。

### A1. `/assets`
1. 5 列固定网格，卡片 174px 宽，所有图片被 `object-cover` 裁成正方形，竖图（351×1238）被裁掉大半。
2. 卡片底部元信息：尺寸文字 11px + 3 个 14px 图标，图标垂直基线不齐、间隙不均。
3. 筛选条（All/Generated/Uploaded）是三个小胶囊，与「Upload image」主按钮体量差距过大，层级断裂。

### G1. `/settings`
1. 单列 600px 卡片堆叠，没有左侧分区导航；「账户设置 / 密码 / AI 中转站 / 主题」混在一起。
2. 字段全是「标签 + 输入框」，无分组标题、无说明文字、无危险操作区。
3. 页面顶部是另一套极简壳（只有 logo + 积分），与其他页面壳不一致。

### M1. `/team`
1. 空状态极简（灰圆 + 两行字 + 一个按钮），没有体现"团队能带来什么"。
2. 页头是白底通栏带，与 PageShell 的纸底 header 不同源。

### D1. `/admin`（Overview）
1. **指标重复**：「Pool normal」在第一行第 4 张和第二行第 2 张各出现一次。
2. 没有任何趋势图 / 最近动态 / 待处理项，8 张数字卡之后整页空白。
3. `consumed_today` 显示 0，缺少单位与对比（vs 昨日）。
4. 侧栏激活态是米色药丸，对比度低（入选文字 vs 背景 ≈ 1.5:1）。

### D2. `/admin/users`
1. 表格无外框；13 行后分页不可见。
2. 角色列是纯文本，无 badge；操作列 4 个 16px 图标间距 24px，贴到右边缘。
3. 「New user」按钮与筛选行分离，视觉上孤立。
