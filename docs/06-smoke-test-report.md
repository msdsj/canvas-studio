## 四、体验亮点（保持）

- **暗色模式**：完整 token 体系，渲染专业（顶栏/侧栏/画布/卡片/表格对比度全部达标）
- **编辑链路**：框选 → 数字标记（互斥展开不遮挡）→ 一键全量发送（单次扣费）→ 骨架屏占位 → 原位自动渲染 → **逐区域完成度检测** → 未完成区域黄标 + 单区域重试
- **号池管理**：状态徽章、批量导入、刷新进度、额度展示完整专业
- **额度中心**：余额/阈值/单价/流水四段式信息完整
- **API 性能**：平均 61ms，无慢接口
